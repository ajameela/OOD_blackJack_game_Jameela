**What did you learn about storing objects in an ArrayList?**
I learned that the ArrayList adjust its size based on what is currently in there or after adjustments such as removing an element.
I enjoyed learning that ArrayLists also have preset methods such as calculating the size, removing an element, adding one, and more. 
This is very helpful for future arrays and could probably be overrode like how we override toString() or equals() if need be.

**What is the difference between data stored in a Card object and behavior provided by its methods?**
The Card object carries the fields related to the object, in this case its cards so it has a Suit, Number, Value, and Picture to go with each card. 
The methods provide the action/behavior done to each card handled. For instance shuffle() shuffles the deck to then get dealt to the player.
